# BoardMate

A web-based student accommodation finder and rental management platform.

## Project Overview

BoardMate helps university students discover suitable boarding places and enables property owners to manage accommodation listings and rental activities.

## Technology Stack

- **Frontend:** React.js, JavaScript, Tailwind CSS, Axios
- **Backend:** C#, ASP.NET Core Web API
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub
